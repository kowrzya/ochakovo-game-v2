# Очаково: твой первый рабочий день

Веб-игра для привлечения студентов и выпускников на практику и работу в «Очаково». Кейс хакатона «Открой Моспром».

Игрок проходит рабочие ситуации на заводе и получает рекомендацию по одному из пяти направлений: лаборатория, цех розлива, технологический цех, склад, инженерная служба. Дальше он может оставить заявку, а HR видит её в панели вместе со статистикой прохождений.

## Проверка

| | Адрес |
|---|---|
| Игра | `https://<адрес>/` |
| HR-панель | `https://<адрес>/admin`, пароль: `<пароль>` |
| Статус сервера | `https://<адрес>/api/health` |

1. Пройдите игру и отправьте заявку (возраст должен быть от 18 лет).
2. Войдите в `/admin`. Новая заявка будет первой в таблице.
3. Записи с меткой «демо» — тестовые данные, их можно скрыть.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run seed   # демо-данные для HR-панели
npm run dev    # http://localhost:5174
```

Очистка данных: `npm run clear:test` удаляет тестовые заявки и прохождения, демо-данные остаются. `npm run seed:reset` пересоздаёт демо-данные.

Пароль HR-панели задаётся в файле `.env`: скопируйте `.env.example` в `.env` и впишите свой пароль. Без `.env` используется пароль `ochakovo-demo`.

| Переменная | Назначение |
|---|---|
| `ADMIN_PASSWORD` | пароль HR-панели |
| `SESSION_SECRET` | ключ подписи входа HR |
| `PORT` | порт сервера (по умолчанию 3001) |
| `DB_PATH` | путь к базе (по умолчанию `data/app.db`) |

## Деплой на Render

- Build command: `npm install && npm run build`
- Start command: `npm run seed && npm start`
- Переменные окружения: `ADMIN_PASSWORD`, `SESSION_SECRET`

На бесплатном тарифе сервис засыпает после простоя: первый запрос идёт около минуты. База сбрасывается при перезапуске.

## Структура

| Путь | Содержимое |
|---|---|
| `client/src/data/scenes.json` | тексты: вступление, история, ситуации, баллы |
| `client/src/data/directions.json` | направления, условия, варианты полей анкеты |
| `client/src/game/` | экраны игры и анкета |
| `client/src/admin/` | HR-панель |
| `client/public/` | логотип, пиктограммы, паттерн, ролики |
| `server/` | API, проверка заявки, база SQLite |

## API

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/events` | событие прохождения для воронки |
| POST | `/api/applications` | заявка |
| POST | `/api/admin/login` | вход HR |
| GET | `/api/admin/stats` | воронка и направления |
| GET | `/api/admin/applications` | список заявок |
| PATCH | `/api/admin/applications/:id` | смена статуса заявки |
| GET | `/api/admin/export.csv` | выгрузка в Excel |
| GET | `/api/health` | статус сервера |

Методы `/api/admin/*`, кроме входа, требуют авторизации.
